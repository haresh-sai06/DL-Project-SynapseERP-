# Module Mapping for Viva

## M1 - RNN / LSTM

- Ledger OCR uses a BiLSTM sequence model after CNN feature extraction.
- Demand forecasting uses an LSTM regressor over SKU demand windows.
- Viva concept link: recurrent hidden state, vanishing gradients, gated memory, sequence-to-sequence alignment.

## M2 - CNN / Attention / Transfer Learning / Autoencoder

- Ledger OCR uses CNN feature maps before the recurrent recognizer.
- TrOCR upgrade uses attention and transfer learning with pretrained transformer encoders/decoders.
- Few-shot product recognition uses a CNN embedding network and triplet/prototypical metric learning.
- Roadmap anomaly detection uses an autoencoder over transaction features.

## M3 - Real-World Deployment and Impact

- FastAPI and Streamlit provide deployable interfaces.
- Hugging Face Spaces, Kaggle, and Colab keep the proof of concept on free-tier infrastructure.
- TensorFlow Lite or ONNX export is the roadmap for offline mobile inference.
- The real-world target is the smallest shop owner: no typing, no technical setup, multilingual inputs.

## What Is Deep Learning vs Software

| Component | Category | Why |
| --- | --- | --- |
| CRNN ledger OCR | Deep learning | Updates CNN/LSTM weights with CTC loss |
| TrOCR fine-tune | Deep learning | Updates transformer weights or adapters on labeled OCR pairs |
| MuRIL order NER | Deep learning | Updates token-classification head with cross-entropy |
| Product metric encoder | Deep learning | Updates embedding network with triplet/ArcFace/prototypical objective |
| LSTM demand forecaster | Deep learning | Updates recurrent weights with regression loss |
| ERP renderer | Software engineering | Converts structured records into dashboard HTML |
| Knowledge graph linker | Software plus embeddings | Entity normalization and linking; may use frozen embeddings |
